# Lesson harness research release

The experimental attention-difficulty model is fitted, benchmarked and connected to the content pipeline. Video, audio, text, PDF and image cached examples pass. Four other requested quality outputs remain blocked because the local annotation audit accepted no synthetic labels. The complete five-quality scientific objective is unfinished.

Read [MODEL_CARD.md](MODEL_CARD.md) for the model, evidence and limitations, and [INTEGRATION.md](INTEGRATION.md) for the backend contract and replay command.

The EEG-informed candidate achieved attention-rating MAE 2.6813 versus 2.6899 for content+TRIBE and 2.6196 for the training mean. That 0.32% improvement over content+TRIBE is uncertain and does not beat the mean or shuffled-EEG control. No useful EEG benefit or measured-fMRI superiority is established.

The frozen native TRIBE branch remains separate and unchanged. Do not describe this artifact as a trained five-quality brain model, individual student simulator, attention measurement device, or validated educational-content optimizer.
